# ARKHER v1 vs v2

**v1** (o que estamos construindo) = aquele nível de *fazer o jogo*:
criar com **Roblox Studio, Blender e Figma**, usar **internet/web**
(fontes licenciadas), **comandos** no PC, **sandbox = o hardware do PC
virtual** (Workspace / Tailscale). O cérebro no chat é **só a ARKHER**.

**Modelo no disco de terceiro:** pode existir, **só para ela aprender**
(professor / operário de treino). **Não entra no chat.**

**v2** = fase 2: nível estúdio (Rockstar / empresa). Não é esta entrega.

## v1 deve

| Peça | Como |
|---|---|
| Roblox Studio | gerar `.rbxlx`/`.rbxmx`/Luau + ponte + VM instala/abre/importa |
| Blender | script `.py` + addon + VM instala/abre/roda |
| Figma | token do user → frames/tokens viram HUD; sem token, kit de UI próprio |
| Web | Wikipedia / Archive / docs oficiais / YouTube com *sua* chave |
| Comandos | jobs permitidos no agente (não shell aberto na internet) |
| Sandbox | Workspace = o PC virtual, o hardware é o da VM |
| Pack | milhares de unidades → treino → gen 6 ~64 M (fase 1 do cérebro) |
| Professor no disco | `.pt` ARKHER destila o próximo; outro checkpoint = operário, nunca runtime |

## v1 NÃO é

- ChatGPT/Gemini/Claude respondendo no recado
- Shell root na internet
- v2 / nível Rockstar
